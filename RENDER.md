### Texture ontology for the renderer

Use a small set of material/finish categories plus numeric knobs. Do not encode every manufacturer as custom drawing code.

Core fields for each color/style:

```ts
type TileTexture =
  | "matte_porcelain"
  | "matte_ceramic"
  | "gloss_ceramic"
  | "handmade_ceramic_matte"
  | "handmade_ceramic_gloss"
  | "handmade_clay_matte"
  | "encaustic_cement"
  | "encaustic_cement_mini"
  | "natural_terracotta"
  | "glazed_terracotta"
  | "rustic_cotto"
  | "saltillo_terracotta"
  | "zellige"
  | "dimensional_porcelain";

type TextureParams = {
  baseColor: string;
  shadeVariation: 0 | 1 | 2 | 3 | 4; // maps to ANSI/industry V0-V4 visual variation
  sheen: number;        // 0 matte, 1 mirror-ish gloss
  grain: number;        // fine surface noise
  clouding: number;     // broad cloudy/pigment variation
  edgeIrregularity: number;
  chipRate: number;
  bevel: number;
  groutJointInches: number;
};
```

Variation reference: ANSI A137.1 uses aesthetic classes V0-V4 for overall color and/or texture variation; V1 is uniform/minimal, V2 slight, V3 moderate, V4 substantial/random. Sources: https://blog.ansi.org/ansi-a137-1-2022-standard-ceramic-tile/ and https://www.ceramictilefoundation.org/blog/how-to-prepare-for-tile-shade-variation

Suggested rendering behavior:

- `matte_porcelain`: solid fill, tiny noise, crisp edges, low bevel, shadeVariation 1-2. Use for Equipe/Kasbah and many basic retail tiles.
- `matte_ceramic`: solid fill, slightly softer edge, low grain, shadeVariation 1-2.
- `gloss_ceramic`: ceramic base plus a clipped diagonal highlight band and small specular glints; shadeVariation 1-3 depending on color.
- `handmade_ceramic_matte`: ceramic base with small per-tile hue/lightness jitter, slight geometry wobble, subtle edge darkening.
- `handmade_ceramic_gloss`: handmade ceramic plus gloss highlight and glaze pooling near edges.
- `handmade_clay_matte`: smooth clay surface, V2-ish variation, minor size/edge wobble, warm undertone in shadows.
- `encaustic_cement`: matte powdery surface, medium clouding, fine speckles, low sheen, small chips, patina/dust overlay. Use for clé, Zia cement, Granada.
- `encaustic_cement_mini`: same as cement, but reduce texture scale and emphasize grout because pieces are small.
- `natural_terracotta`: clay-orange base, medium/high clouding, pores, darker edge burn, no gloss unless sealed.
- `glazed_terracotta`: terracotta body plus gloss glaze, stronger shade variation, pooling at low spots.
- `rustic_cotto`: rougher terracotta/cotto surface, moderate shade and surface variation, larger pits and edge chips.
- `saltillo_terracotta`: highest rustic clay variation; add striping, lime-pop dots, hairline cracks, larger chips, uneven edges.
- `zellige`: V4-level per-tile color jitter, wavy quadrilateral surface patches, strong gloss highlight, uneven hand-cut edges, glaze pooling, occasional dark edge shadows.
- `dimensional_porcelain`: manufactured porcelain with raised/star relief; for now render as flat color plus bevel/shadow, not true geometry.

### Grout defaults

Use manufacturer-specific grout width when present, otherwise choose by texture:

- Equipe/Kasbah porcelain: default 1/8" until the official installation guide is parsed.
- Fireclay Original Ceramic: 3/16" for non-rectified handmade tile; 1/8" if a rectified style is selected.
- clé cement: 1/16".
- Zia cement: 1/16".
- Clay Imports handmade clay: 1/8" to 1/4"; use 1/8" default in the app.
- Rustic terracotta/Saltillo: 1/4" default unless product specifies otherwise.
- Zellige: 1/16" visual default, but expect irregular lines rather than constant width.

Grout color seed list:

- White `#f2f0e8`
- Warm White `#e4dccd`
- Alabaster `#d8d1c2`
- Biscuit `#cbbfae`
- Warm Gray `#aaa59b`
- Timberwolf `#8f8c84`
- Silver `#c0c0bc`
- Charcoal `#404040`
- Black `#151515`

Implementation note: keep grout as its own material layer. Many cement/zellige sources warn against high-contrast grout because it can stain, haze, or visually overemphasize irregular edges, so the UI should allow contrast but default to near-color or warm-neutral grout for handmade materials.
